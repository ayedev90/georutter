Open vector parcel boundaries with parcel ID (id/idu) and fiscal area (contenance in m²) are published under Licence Ouverte v2.0 across 96 metro depts, 5 DROMs (incl. Mayotte), 977 & 978 (~94.7M parcels; Strasbourg included since Sept 2025, 0 TIFF sheets left). Bulk datasets live on Cadastre Etalab (cadastre.data.gouv.fr: 21.45 GB cadastre.parquet or per-dept GeoJSON/SHP; geojson/france/ lacks parcels), DGFiP EDIGÉO, and IGN .7z; query APIs are IGN WFS 2.0.0 and API Carto. Autonomous COMs (975, 986, 987, 988) fall outside national PCI: 987 DXF lacks area, 988 serves centroids only, 975 uses WMS/SPA, 986 lacks unified cadastre.

Confidence reason: Verified live downloads (GeoJSON, SHP, GeoParquet S3 Range footer, Atom .7z), both query APIs (WFS, API Carto), DGFiP/IGN PDF specs, and all 4 overseas collectivity portals on 2026-11-15.

Main caveats

  • Etalab geojson/france/ and shp/france/ contain NO parcels (communes/sections/feuilles only); use cadastre.parquet (21.45 GB) or per-department files.
  • Géoplateforme /wfs/ows?REQUEST=GetCapabilities returns JMX metrics instead of XML; call /wfs?SERVICE=WFS&VERSION=2.0.0&REQUEST=GetCapabilities for caps, then /wfs or /wfs/ows for GetFeature.
  • API Carto OpenAPI YAML omits idu & contenance though live JSON returns both; Paris/Lyon/Marseille require commune INSEE (e.g. 75056) + code_arr (101), not 75101.
  • 4 overseas collectivities (975 SPM, 986 Wallis, 987 Polynésie, 988 NC) are excluded from national DGFiP PCI: NC publishes centroids only, Polynésie 2022 DXF lacks area.
  • Fiscal/illustrative geometry only (Napoleonic sheets EMQ 0.5-5m; excludes domaine non cadastré public roads/rivers/shores & 29083/29084; some null contenance).

s001Cadastre Etalab (DINUM / data.gouv.fr)

DINUM / Etalab (from DGFiP PCI Vecteur) · Official · GeoParquet (21.45 GB national), GeoJSON (.json.gz per dept/commune), Shapefile (.zip per dept/commune), MBTiles · Direct download · License: Licence Ouverte / Open Licence v2.0

Caveats

  • The geojson/france and shp/france directories contain no parcels. Use the national GeoParquet or department files.
  • GeoParquet is 21.45 GB, contains several object types and mixed CRSs: select parcelle and read geom_srid.
  • Fiscal contenance can be null; parcel geometry is illustrative, not a legally binding boundary.

Caveats

  • Use /wfs for GetCapabilities: /wfs/ows returned metrics for that request in the inherited test.
  • Paginate at most 5,000 features per page. Paris/Lyon/Marseille use commune codes plus code_arr.

Example request

curl -sSL 'https://data.geopf.fr/wfs/ows?SERVICE=WFS&VERSION=2.0.0&REQUEST=GetFeature&TYPENAMES=CADASTRALPARCELS.PARCELLAIRE_EXPRESS:parcelle&CQL_FILTER=code_dep%3D%2775%27%20AND%20code_arr%3D%27101%27&COUNT=5&OUTPUTFORMAT=application/json'
