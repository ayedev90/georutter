Germany cadastral parcels data sources

Where can I get cadastral parcel boundaries (geometry) for all of Germany, with parcel identifier and area, as a bulk download or as a queryable service?

Answer

No free single dataset or API covers all of Germany. Cadastre (ALKIS) is run by the 16 Bundesländer: 15 publish free parcel polygons, 20-char parcel IDs (Flurstückskennzeichen), and official area (m²) without owners via state WFS, OGC API Features, or bulk downloads. Bavaria (LDBV) omits free vector parcels (FS-BY costs 56,000 EUR/yr; free WMS Parzellarkarte lacks parcel IDs). Only paid quarterly bulk contracts via ZSHH FS-DE (from 27,000 EUR/yr) + FS-BY (56,000 EUR/yr) cover all 16 states (~83,000+ EUR/yr, no API). BKG FS-DE (15 states) is restricted to V GeoBund federal agencies; Esri flstk_DE gives a free CC BY 4.0 REST API for those 15 states.

Main caveats

  • Bavaria (~20% of Germany) omits free vector parcels: LDBV FS-BY costs 56,000 EUR/yr (ALKIS 1.80 EUR/parcel), WFS needs framework contracts, and free Parzellarkarte WMS is raster-only without parcel numbers.
  • Official all-16 consolidation exists only via paid quarterly bulk Shapefiles from ZSHH FS-DE (>=27,000 EUR/yr) + LDBV FS-BY (56,000 EUR/yr), with no API; BKG FS-DE (15 states) is restricted to V GeoBund agencies.
  • The 15 Open-Data states use incompatible schemas (ave:Flurstueck, adv:AX_Flurstueck, cp:CadastralParcel, custom nora/BE), CRS (EPSG:25832/25833/4326), and WFS CountDefault caps (10k-1M), plus RP offers bulk ZIP only.
  • Public ALKIS products omit owner/title records (Eigentümer/Grundbuch) and are not legally binding extracts: arc densification adds non-authoritative vertices, and RP/SL include Flurbereinigung pseudo-parcels.
  • In Esri flstk_DE (53.75M features, excl. Bayern), Shape__Area is distorted Web Mercator EPSG:3857 (~2.3x true area at 49 deg N) — use Amtliche_Fläche__m__ — and unindexed WHERE queries time out.
