Germany battery storage in permitting data sources

Where can I get a list of stand-alone battery storage (BESS) projects currently in permitting in Germany, with location, power (MW), developer, permitting stage and date?

Answer

No single German registry tracks BESS in permitting. Most stand-alone BESS are not BImSchG-listed and undergo confidential district Baugenehmigung (~400 authorities; >=4 MW within 200 m of substations privileged per § 35(1) Nr.12 BauGB since 23.12.2025) or municipal Bebauungsplan procedures. Closest official source is BNetzA's MaStR (753 planned >=1 MW units, 13.1 GW; 303 non-EEG/non-backup), but pre-grant filing is voluntary and only 65 hold post-grant permit data. Municipal consultations publish unstructured on UVP-Verbund and state DiPlanung/Bauleitplanung portals; EC JRC (WoodMac-backed) adds partial pipeline data.

Main caveats

  • Pre-permit MaStR registration is voluntary for non-BImSchG projects; 753 planned >=1 MW BESS in MaStR vs 18,158 grid requests (573.5 GW) and 1,937 commitments (54.2 GW) in 2025.
  • Pending Baugenehmigungen (~400 district Bauaufsichtsbehörden) are non-public administrative files; MaStR's Genehmigung schema requires a mandatory grant date (Datum), so pending applications cannot appear there.
  • No explicit stand-alone boolean exists in MaStR: 443/753 planned >=1 MW units link to an EEG facility (many PV+BESS), while 303 non-EEG/non-backup units serve as an imperfect stand-alone proxy.
  • 276/753 planned >=1 MW MaStR battery units already carry overdue planned commissioning dates (< 2026-11-15), inflating the apparent active pipeline.
  • MaStR list JSON returns GenehmigungRegistrierungsdatum (upload date), not actual Genehmigungsdatum / DatumDerAntragstellung (which require scraping unit detail HTML or parsing the 3.2 GB XML dump).
