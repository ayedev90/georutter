What is GeoRutter?

GeoRutter is a directory of geospatial data sources, organized by country and question. It helps AI agents and analysts find the organizations, datasets and services that can answer a territorial question.

How to use it

Choose a country and topic on the source directory. Each guide identifies sources, access methods, relevant fields, dates and limitations. The JSON card provides a concise answer, and the detail includes further evidence and instructions.

About the research

Guides record research and access-check dates where available. Coverage and access may change, so consult the source and the guide’s caveats when using the data.

Contact

Report an issue, suggest a source or request a guide through GeoRutter on GitHub.
