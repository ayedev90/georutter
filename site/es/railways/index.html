Spain railways data sources

Where can I get the railway network (geometry) of Spain, with line type, electrification, infrastructure manager and traffic?

Answer

Geometry with electrification, gauge and track count for the whole network (Adif plus FGC, Euskotren, SFM, metro, tram) is in IGN's INSPIRE WFS (60,018 links, CC BY 4.0). Line type is partial (train/metro/tram on 497 lines). Manager is only an administration level there; ERA RINF gives a manager code for 2,520 Adif sections. Traffic exists only as train-km per axis and top-10 lines (CNMC PDF). Adif's own WFS is blocked to automated clients.

Main caveats

  • IGN attributes are separate features linked to links; many links lack electrification (38,120) or track count (37,336) of 60,018. GML only.
  • ERA RINF geometry is a 2-point chord per section and only manager code 0071; the code was not confirmed as Adif by any page.
  • Traffic is per axis and top-10 lines only, RFIG only (no FGC, Euskotren, SFM, metro or tram).
  • ideadif.adif.es, www.adif.es and www.transportes.gob.es answered 403 to automated clients; Adif's own WFS and network statement were not read.
  • Network lengths differ: Adif 15,654.1 km (OFE 2024), RFIG 15,678 km (CNMC 2025), RINF sections sum 15,537 km.
