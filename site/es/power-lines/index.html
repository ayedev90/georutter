Confidence

No open official Spanish dataset provides all transmission and distribution line routes with exact voltage, operator and status. Nationally, IGN Base Topográfica Nacional (BTN 0710L_LIN_ELEC via vt-btn.idee.es MVT API or CNIG GeoPackage) gives overhead routes and banded voltages (<100, 100-150, 220, 400 kV), excluding underground/submarine cables, operator and status. Official operator and exact >=50 kV voltage exist for Andalucía (MIEA WFS) and transmission status appears in schematic MITECO 2025-2030 PDFs; REE Infored (request form) and Inkolan (paid DWG) hold operator plans, while OpenStreetMap/OpenInfraMap partially covers all fields nationally.

Confidence reason: Verified official regulator, ministry, TSO, IGN/IDEE, regional WFS, ENTSO-E, OSM/OpenInfraMap, and Inkolan endpoints directly with live queries and file downloads.

Not published: No open national GIS vector dataset tracks operational status for both transmission and distribution lines; distribution status is unpublished as open GIS.

Main caveats

  • IGN BTN 0710L_LIN_ELEC excludes all underground and submarine cables (lines stop at transition towers) and omits operator and status fields.
  • CNMC Circular 6/2025 access-capacity maps publish substation point nodes only, not line routes; none of Spain's 325 active DSOs publish open line-route GIS.
  • CNIG Centro de Descargas (BTN_T_Energia GeoPackage) drops automated HTTP requests (empty reply); programmatic access works via IGN/IDEE MVT tiles at vt-btn.idee.es.
  • ENTSO-E Grid Map explicitly warns elements are not at exact geographic coordinates; REE public GeoRED MapServer exposes only 63 sample circuits.
  • OpenStreetMap/OpenInfraMap maps 128,460 km in Spain (2026-11-15), but 19.5% lacks voltage tags and ~85% of lines in Madrid/Granada samples lack operator tags.
