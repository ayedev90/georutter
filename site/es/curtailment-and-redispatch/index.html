Spain curtailment and redispatch data sources

Where can I get renewable curtailment and redispatch volumes in Spain, by zone or node and by period?

Answer

REE (the TSO) publishes monthly renewable curtailment from day-ahead technical constraints by grid node (ERNI, GWh, PDF on ESIOS; Peninsula plus Baleares/Canarias in MWh). Redispatch volumes (technical-constraint energy up/down, PDBF phase I and real time) are open as national monthly/yearly series via the REData API, not by node. Per-unit data is restricted to market subjects; economic curtailment and daily series were not found public.

Main caveats

  • ERNI by node is a monthly Power BI PDF export (no CSV): the table lists only the Top 30 nodes (Oct 2026: 355 of 578 GWh); the chart shows more nodes but its values need image/chart reading.
  • ERNI counts only D-1 phase I technical constraints vs PDBF, renewable units with specific electrical location; the report itself says node values may not match the aggregate monthly value on ESIOS.
  • Colours in the PDF legend decide RTT vs RTD: text extraction loses the mapping (Oct 2026: RTT 569.4 GWh, RTD 8.7 GWh read from the rendered chart).
  • REData energia-restricciones has no unit field; values match REE report GWh x1000 (MWh). Down values are negative. Wider period/geo options (day, baleares, ccaa) returned HTTP 400.
  • Redispatch (restricciones tecnicas) is not renewable-only: it includes gas/other units scheduled for voltage control and stability; do not equate it with renewable curtailment.
