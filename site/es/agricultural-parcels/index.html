Spain agricultural parcels data sources

Where can I get agricultural parcels (geometry) in Spain, with declared crop or land use and irrigation, by year?

Answer

FEGA (Ministry of Agriculture) publishes the national 'Cultivo declarado' (CAP declaration lines) as polygons with declared product code and S/R (dryland/irrigated) flag: bulk GeoPackage/SHP for campaign 2025 and an OGC API with campaign 2026 (CC BY 4.0). Land use and irrigation coefficient per SIGPAC recinto are in the FEGA recintos files. Earlier years are not official at national level: use Catalonia (2015-2026), Madrid (2022) or third-party GeoParquet (2021-2023, 2022-2024).

Official national: 2025 bulk + 2026 API only. Earlier years from regions (Catalonia 2015-2026) or third parties (2021-2025).

Not published: FEGA says HVD covers current and previous campaign only (fega.gob.es sigpac page, ATOM spec PDF); no earlier national campaign found on atom/, sigpac-hubcloud geopackages/ or datos.gob.es.

Main caveats

  • FEGA sources disagree on what 'cultivo declarado' is: pages say previous campaign (2025) but the OGC API returns expedientes numbered 2026 (17.9M features). Check exp_num before citing a year.
  • The OGC API recintos collection has no uso_sigpac or coef_regadio fields; those only exist in the ATOM/provincial recintos GeoPackages.
  • Third-party GeoParquet and Zenodo copies drop parts: Zenodo has no irrigation and one crop per parcel; source.coop keeps only the main crop and an undocumented irrigation_system column.
  • Declared lines cover only farmers who filed the CAP single application, not every agricultural parcel in Spain.
  • Regional series differ in code lists and geometry (Aragon CSV has no geometry; Catalonia WFS is EPSG:25831, Madrid EPSG:25830).
