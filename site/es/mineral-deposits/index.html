IGME’s BDMIN catalogues Spanish mineral occurrences and operations using point layers with commodity, size-class and status fields. Operators publish tonnage and grade for selected projects; MSP-REFRAM offers historical data for selected refractory metals. BDMIN record queries and completeness could not be verified.

Confidence reason: Descriptions and schema were inspected, but data queries and completeness could not be verified.

Main caveats

  • The inventory contains recorded occurrences, not proof that every deposit is known or commercially viable.
  • Layer descriptions and fields were inspected; record counts, individual values and coordinate quality were not verified.
  • Status and size classes can be historical; confirm the observation date before treating them as current.
  • Do not treat a qualitative size class as measured tonnage or ore grade.
  • The occurrence layer metadata has an anomalous southern extent of 3.675° N; affected records could not be identified.
