No single national file has geometry, category, owner and AADT for all Spanish roads. The Ministry of Transport's HERMES ArcGIS REST service gives State-network (RCE) section lines with owner, road type and IMD (vehicles/day, 2020-2024 per section) as open API. IGN's IGR-RT covers all roads of every owner with category and owner but no traffic. IMD on regional roads is published region by region (Valencia, Catalonia, Navarre, Castilla y Leon tested).

Confidence reason: HERMES and 4 regional sets were queried and counted; the IGR-RT owner/category files and 12 regions' IMD were not opened or downloaded; ministry site rejects automated clients.

Main caveats

  • HERMES holds several years per section: filter Dato_hasta (epoch ms) to the newest, or you get duplicates (23,113 rows, 11,338 unique road+PK ranges). Row id 0 is empty. Valido_hasta is empty in all rows.
  • In HERMES layer 198 IMD_asc/IMD_desc are percentages of the total (they add to 100) although the data dictionary says vehicles/day; IMD_asc is null in 6,443 rows.
  • HERMES IMD lines cover the State network only (Titular=Estado in 23,046 of 23,112 rows); the station layers (195, 151) return HTTP 400 to every query tried.
  • IGR-RT is the only nationwide owner/category source but its download is a browser button (link '#'); curl got an empty reply from CNIG. Licence compatible with CC-BY 4.0. No traffic field.
  • Regional IMD sets differ: Catalonia and Navarre give points at stations, Castilla y Leon has no geometry, Valencia has lines (GML only). Years differ per region.
