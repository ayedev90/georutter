No single national list of grid connection requests with project, technology, MW, node, status and date exists in what was checked. REE publishes monthly (xlsx/pdf) the individual requests for demand and storage-as-consumption at transport nodes >=220 kV (ID, date, node, position, MW; no project name). Generation and distribution queues appear only aggregated per node/position (REE CSV, CNMC ArcGIS layers, distributor CSVs) or per technology and region (REE GW PDF).

Confidence reason: Core files opened and tested; negatives rest on REE, CNMC, MITECO and e-distribucion pages. REE interactive map data endpoint not found; other distributors and regions only sampled.

Main caveats

  • The REE demand list covers only demand and storage acting as consumption at nodes >=220 kV; it is not the generation queue and has no project names.
  • Generation queue is aggregated (GW by technology and region, MW by node/position); never sum node values: CNMC says capacities are not directly additive.
  • The REE demand list is valid one month (publication to 'Fecha fin del mes de publicacion'); older months stay downloadable by changing the month in the file name.
  • Distribution-level requests: only 'admitted and unresolved' MW per substation bar (CNMC and distributor files); over 300 distributors exist per CNMC, 61 appear in the CNMC layer.
