United States roads data sources

Where can I get the road network (geometry) of the United States, with road category, owner and traffic volume (annual average daily traffic)?

Answer

FHWA's Highway Performance Monitoring System (HPMS) is the national source: state-reported section lines for public roads, each with functional system (f_system), legal owner (ownership) and AADT. BTS serves it as per-state, per-year ArcGIS services (52 jurisdictions) and FHWA as one 2025 table (17,361,652 rows). Codes are numeric and decoded in the Field Manual. AADT is required only on Federal-aid roads; local roads rarely have it. Count stations come from state GIS (Caltrans: state highways only).

Local search terms

  • HPMS Spatial All Sections — Name of the national HPMS section table on data.transportation.gov; add the year.
  • HPMS_FULL_<state>_<year> — Name pattern of the BTS state ArcGIS services (e.g. HPMS_FULL_DE_2025).
  • Federal-aid highways — Roads eligible for federal aid; the extent where HPMS requires AADT.
  • F_SYSTEM — Functional system code 1-7 (Interstate to Local).
  • OWNERSHIP — Legal owner code of the roadway.
  • AADT — Annual average daily traffic.
  • ARNOLD — All Road Network of Linear Referenced Data, the HPMS geometry.
  • NTAD — National Transportation Atlas Database published by BTS.

Main caveats

  • Rows are linear-referenced sections, not roads or count stations. Row counts change by year and state (CA 958,293 in 2024 vs 803,191 in 2025); the README admits overlapping and gapped geometry.
  • AADT is bidirectional on two-way sections and directional on one-way roads and ramps. Growth factors may be applied to older counts, so data_year is not the count year.
  • AADT is required only on Federal-aid highways: CA 2024 has it on 21 of 488,722 local rows, DE 2025 on 23,276 of 65,459. Rural minor collectors are also often missing.
  • f_system and ownership are integer codes with no domains in the services. Decode them with the Field Manual (the DOI resolves to the December 2016 edition; errata exist).
  • The 2025 README flags North Dakota and New Jersey as missing substantial portions of data. The shortfall was not measured here.
  • fhwa.dot.gov and highways.dot.gov pages refused default curl requests (403). Data services, GitHub and data.transportation.gov were reachable.
