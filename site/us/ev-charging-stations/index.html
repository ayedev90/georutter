The DOE Alternative Fuels Data Center (AFDC) Station Locator is the national official list. Its API (developer.nlr.gov) gives, per station location, coordinates, access, status, charging network and ports by level, and per charging unit the connector types, port counts and kW. On 2026-11-26 it held 84,725 public operating station locations with 267,448 charging ports (station_counts), plus 220 planned. 'Operator' is the network/provider field, not a separate CPO name, and kW is missing for part of Level 2 ports.

Confidence reason: AFDC API, docs and counts pages were opened and tested on 2026-11-26 with a full Connecticut extract and a 97% national ports CSV read; operator limitation confirmed in field lists.

Local search terms

  • Alternative Fueling Station Locator — AFDC tool and database whose API and download hold the national charging station list.
  • alt-fuel-stations/v1 fuel_type=ELEC — API endpoint and filter that return EV charging stations on developer.nlr.gov.
  • station locations | charging ports — AFDC's two counting units in its state tables.
  • EVSE port — Electric vehicle supply equipment port; the AFDC unit behind Level 1/Level 2/DC Fast counts.
  • Level 2 / DC Fast — Charging levels used as categories in AFDC and state counts.
  • CPO — Charge point operator; defined by AFDC but not a field in its data.
  • NEVI (23 CFR 680) — Federal standards for federally funded chargers, including 680.116(c) third-party data sharing.
  • OCPI — Open Charge Point Interface, the protocol networks use to send data to AFDC and third parties.

Main caveats

  • Count units differ: AFDC 'station' = location; station_counts.total and state tables for electric count charging ports; connector entries can exceed ports.
  • API defaults include private, planned and temporarily unavailable stations; filter access=public&status=E (planned = status=P with expected_date).
  • Operator is the charging network/provider (ev_network), not a CPO name; AFDC lists 17,948 Non-Networked ports (US and Canada) with no operator name.
  • California's CEC reports 98,251 public ports (data as of 2026-06-30, adds PlugShare and surveys) vs 70,178 in AFDC for CA on 2026-11-26: different sources, not equivalent.
  • The legacy developer.nrel.gov API host no longer resolves; use developer.nlr.gov. DEMO_KEY is rate-limited; the CSV form asks for name and email.

curl 'https://developer.nlr.gov/api/alt-fuel-stations/v1.json?api_key=DEMO_KEY&fuel_type=ELEC&country=US&state=CT&access=public&status=E&limit=all'
