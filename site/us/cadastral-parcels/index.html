No single official federal cadastral parcel dataset or registry covers all of the United States; parcel mapping is maintained locally by 3,000+ counties and towns. Per NSGIC 2025 GMA, 36 states + D.C. run statewide programs, and only 22 (43%) publish 100% open parcels via API or bulk download (e.g., FL, NC, WI, DC); others are partial (NY, TX 403-blocked), county-only (CA), or web-only. For free nationwide bulk GeoParquet (158.1M polygons, parcelid, calcarea), use Hugging Face landrecords/us-parcel-layer (CC BY-NC-ND 4.0, non-commercial only). Commercial nationwide bulk/API access is available via Landrecords.us, Regrid, ReportAll, LightBox, and ATTOM.

Confidence reason: Verified via FGDC/NSGIC 2025 GMA report, sampled official state/county REST APIs and Menominee WI shapefile download, HF schema/WKB/area validation, and 5 commercial vendors.

Local search terms

  • APN / AIN / PIN / PID — Assessor's Parcel Number / Assessor Identification Number / Parcel Identification Number used by county assessors
  • SSL (Square, Suffix, Lot) — Cadastral tax lot identifier used in Washington, D.C.
  • SBL / PRINT_KEY — Section-Block-Lot and Print Key parcel identifiers used in New York State
  • Plat / Subdivision Plat (Book & Page) — Official recorded survey map subdividing land into numbered blocks and lots
  • Tax Roll / Assessment Roll / Property Card — County tax assessor record listing Parcel ID, owner, legal description, acreage, and assessed values
  • PLSS (Public Land Survey System) — Federal rectangular survey grid (Township, Range, Section) in 30 public-domain states; not individual tax parcels

Main caveats

  • No federal cadastral registry exists: land records sit across 3,000+ counties/municipalities. Only 22 of 51 state/D.C. jurisdictions have 100% open public parcels via API or bulk download (NSGIC 2025 GMA).
  • Free nationwide HF GeoParquet (112.8 GB, 158.1M rows) is CC BY-NC-ND 4.0 (no commercial use or derivative redistribution); HF datasets-server /filter SQL failed in tests (422/502).
  • HF README vs file mismatch: README says ownername/owneraddr are REDACTED and describes archive.zip (~115 GB, 157M), whereas the repo serves LR_PARCEL_NATIONWIDE_FILE_US_2026_Q3.parquet (158.1M rows, row 0 has populated ownername).
  • Area semantics and IDs vary locally: WI Menominee shapefile distinguishes GISACRES, ASSDACRES, and DEEDACRES and marks tribal parcels PARCELID='TRIBAL'; official layers report area in projection units (ft2 or m2).
  • Automated bulk access is blocked on some official portals: Texas TxGIO StratMap ZIP downloads returned HTTP 403 CloudFront errors and its MapServer had Query disabled (400).
