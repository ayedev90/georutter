United States grid connection queue data sources

Where can I get the list of grid connection requests in the United States, with project, technology, capacity (MW), connection node, status and date?

Answer

There is no single official national list: each ISO/RTO publishes its own. MISO (JSON), CAISO and NYISO (Excel) were downloaded and give technology, MW, POI, status and dates; only NYISO names developers. PJM has a web viewer with export links not tested; SPP, ISO-NE, ERCOT not retrieved. Berkeley Lab's Queued Up compilation (7 ISOs plus ~50 non-ISO areas) was blocked here.

Local search terms

  • Interconnection queue — Ordered list of generator requests to connect to the transmission grid.
  • POI (point of interconnection) — Requested substation or line where the project would connect.
  • ERIS / NRIS — Energy Resource / Network Resource Interconnection Service (MISO svcType values).
  • DPP (Definitive Planning Phase) — MISO study cycle label such as DPP-2023.
  • Cluster study — Requests studied in batches (CAISO clusters, PJM Transition Cycles, NYISO cluster projects).
  • ISO/RTO — Independent System Operator or Regional Transmission Organization.

Main caveats

  • Operator lists are regional and use different fields, MW bases and status codes; do not add them up as a national total.
  • A connection request does not prove permits, financing or construction.
  • MISO and CAISO omit developer names; NYISO status is a numeric code without legend.
  • Withdrawn and done requests sit in the same files as active ones; filter by status before counting.
  • The MISO JSON endpoint is undocumented and no licence was found for any operator file.
